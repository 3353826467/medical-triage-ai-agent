# 智能问诊 AI 客服系统 · 项目简介

技术栈：FastAPI + LangChain + Vue 3 + Vite + Milvus，OpenAI 兼容协议可一键换模型
症状咨询 / 智能分诊 / 报告解读 / 就医 FAQ 四大能力，统一意图路由自动分发
智能分诊输出首诊科室 + 四级紧急度 + 可能情况（含概率与依据）+ 可执行建议，JSON 结构化
报告解读逐项翻译检验 / 影像 / 病理指标，自动标注偏高偏低，支持 txt、docx、pdf 上传
医疗安全护栏：10 类红旗症状短路返回急诊指引，不调模型、下沉至链路层不可绕过
RAG 检索增强：Milvus 2.x 生产 / 本地哈希向量降级，答案附来源与相关度可溯源
SSE 流式输出 + 多轮会话，患者画像（年龄/性别/病程/既往史）参与分诊
全链路降级：无 API Key、无 Milvus 亦可完整启动并给出合理答复
